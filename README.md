TaskMate – Flutter To-Do App

TaskMate is a simple task management application built using Flutter. It helps users organize daily tasks and track their progress.

Features

- Add and delete tasks
- Mark tasks as completed
- Organize tasks by category
- Set task priorities
- Light mode and dark mode
- Save tasks so they remain available after refreshing the app

Technologies Used

- Flutter
- Dart

How to Run

1. Install Flutter.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run "flutter pub get".
5. Run "flutter run -d chrome" to launch the web app.
